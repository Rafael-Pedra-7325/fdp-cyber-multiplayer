# 🃏 FDP: Edição Cyber-Noir (+18) — Multiplayer até 12 Jogadores

Versão web multiplayer em tempo real do jogo de cartas **FDP (Foi De Propósito)**, construída em **Python (Flask + Flask-SocketIO)** com visual dark neon responsivo para jogar direto do celular.

## ✨ Recursos Principais
- **Multiplayer até 12 pessoas**: cada jogador acessa no próprio aparelho via código, link direto, WhatsApp ou QR Code.
- **Mais de 1.050 cartas +18**: baralho original completo + 4 expansões temáticas selecionáveis no lobby + Cartas Coringa editáveis ao vivo.
- **8 Modos de Jogo**: Clássico, Rando Cardrissian (bot fantasma), Aposta Arriscada (Dobro ou Nada), Reinado do FDP, Democracia Caótica, Relâmpago (25s), Caos Supremo e Sobrevivência/Combos.
- **Regras oficiais completas**: *Compre 2, Jogue 3* em cartas triplas, *Troca Tática (Reboot)*, revelação anônima carta por carta, reações flutuantes ao vivo e reconexão automática se a tela do celular apagar.
